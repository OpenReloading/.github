# Code of conduct

Every RangeFoundry project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), in every project space: the repositories, their issues, pull requests and discussions, and the Discord server.

Report unacceptable behavior to the maintainers privately: on the repository's Security tab, choose "Report a vulnerability" (GitHub private reporting, as the [security policy](https://github.com/OpenReloading/.github/blob/main/SECURITY.md) describes). Reports are handled in confidence.
