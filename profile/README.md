# OpenReloading

Open hardware and software for ammunition reloading.

| Repository | What it is |
|---|---|
| [AutoLever](https://github.com/OpenReloading/AutoLever) | Pneumatic drive for a reloading press: build guide, 24 V DC relay logic |
| [Feeder](https://github.com/OpenReloading/Feeder) | Parametric brass and bullet collator, built in build123d |
| [BuildGuide](https://github.com/OpenReloading/BuildGuide) | Interactive build guides for hardware from one JSON file |
| [Artwork](https://github.com/OpenReloading/Artwork) | Logos and wordmarks of OpenReloading and its projects |

Questions and ideas: [Discord](https://discord.gg/KkYJ5fdukR).
