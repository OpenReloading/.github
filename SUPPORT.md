# Support

Where to ask about a RangeFoundry project:

- A question about using it, or something its documentation does not explain: open an issue with the question form in that repository.
- Something that does not work: open an issue with the bug report form.
- A chat with other users: the [RangeFoundry Discord](https://discord.gg/hUCSjDYNaa).
- Questions and ideas about Ballistics: [its Discussions](https://github.com/OpenReloading/Ballistics/discussions).
- A vulnerability: report it privately, as the [security policy](https://github.com/OpenReloading/.github/blob/main/SECURITY.md) describes.
