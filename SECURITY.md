# Security policy

This policy applies to every OpenReloading repository without a `SECURITY.md` of its own.

## Supported versions

Only the latest release of a project receives fixes while it is in early alpha (0.0.x).

## Reporting a vulnerability

Report it privately, not as a public issue, a discussion or on Discord: open the repository's Security tab and choose "Report a vulnerability" (GitHub private vulnerability reporting). Include the affected version, the component and the steps to reproduce. The maintainers answer in the advisory and publish it with the fix.
